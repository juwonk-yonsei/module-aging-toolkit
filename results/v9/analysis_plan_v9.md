## 2. Definitions

Screen competitive nulls

- Both nulls are applied to every estimable pair. The two nulls are the instruction 6 nulls: a size-matched random gene set, and a permutation of the coefficients.
- BH is applied, separately for each null, across every estimable pair.

Two specificity definitions

- set-specific (screen): the random-gene screen FDR is below 0.10
- weight-specific (screen): both screen FDRs are below 0.10

Two gates

- Program level (screen): robust and IPF-specific and set-specific (screen)
- Clock direction (screen): robust and IPF-specific and weight-specific (screen)

robust and IPF-specific keep the r5 definitions. The classical, HC3, and Freedman–Lane family, and the IPF-versus-COPD contrast, are the instruction 6 gate. Freedman–Lane uses B = 5000.

Permutation count, two stages

- Stage 1: B = 1,000 for every estimable pair, for both nulls.
- Stage 2: a pair whose stage-1 p is below 0.05 on either null is extended to B = 10,000 on both nulls. The first 1,000 draws are kept, and 9,000 new draws are added.
- A pair that is not extended keeps its stage-1 p.
- Check: if a pair that was not extended has a screen FDR below 0.10, record the replicate and the pair. That can happen only when the number of discoveries on that null exceeds 125.

p = (1 + count of null statistics at least as large as observed) / (B + 1). A count of zero is written p < 1/(B+1).

## 4. Pre-specified criteria

A false hit is a hit in a pair with no planted effect. That is every S4 hit, and every S2a hit whose cell type was not planted.

Program level (screen)

| item | criterion |
|---|---|
| Q1 | program-level passes among all S4 pairs are at most 1% |
| Q2 | set-specific (screen) among false hits is at most 10% |
| Q3 | set-specific (screen) among all S2a hits is at most 10%. This is the instruction 7 P2 denominator. The planted-cell-only rate is reported beside it |
| Q4 | report the cell-type MDE80 for S1a and S1b. No threshold |

Judgment: if Q1, Q2, and Q3 all hold, "screen 기준 프로그램 수준 정의 채택 가능". If any fails, "채택 불가", and the failed items are named.

Clock direction (screen): the same Q1–Q4 with weight-specific (screen) and the clock-direction pass in place of set-specific and the program-level pass. The same judgment rule.

If a Q2 denominator is 0, the rate is left blank and the criterion is met.

MDE80 uses the simulated grid 1.0, 1.5, 2.0. It is the smallest grid point at which the pass rate among planted targets is at least 0.80, with linear interpolation between the surrounding points. If the rate is already at least 0.80 at 1.0, the value is "1.0". If it never reaches 0.80, the value is "> 2.0". A blank rate makes the MDE blank. The pass rate for the program definition is the program-level pass. The pass rate for the clock definition is the clock-direction pass.

Comparison, not judged. On the same replicates, the within-hit definition from instructions 6 and 7 is computed from the same two-stage p-values. Its BH family is the hit set only. set-specific (within) is a hit whose within-hit random-gene FDR is below 0.10. weight-specific (within) is a hit whose two within-hit FDRs are both below 0.10. Report, side by side, the specificity rate among false hits, the specificity rate among all S2a hits, and the MDE80.
