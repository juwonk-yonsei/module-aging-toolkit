## 2. Shared definitions

The gate is the r5 definition.
- hit: classical FDR < 0.10. Unestimable tests are removed from the Benjamini-Hochberg family.
- robust: all three inferences have FDR < 0.10.
- IPF-specific: the primary IPF-control FDR < 0.10 and the joint-model IPF-COPD FDR < 0.10.
- module-specific: inside the hit set, both competitive nulls have FDR < 0.10.

Final categories (6):

| category | condition |
|---|---|
| pass | robust and IPF-specific and module-specific |
| robust, IPF-specific, not module-specific | robust, IPF-specific, and not module-specific |
| robust, module-specific, shared | robust, module-specific, and not IPF-specific |
| robust only | robust, and neither of the two rows above |
| hit only | hit, and not robust |
| dropped | not a hit |

Standardized effect d: the score difference in units of the primary-model residual SD of that cell type and module. Same unit as manuscript Fig. 4a. In Part A, each replicate computes this residual SD on the background, before the effect is planted.

True category by scenario:

| scenario | true category |
|---|---|
| S1a, S1b (gold) | pass |
| S2a (random broad shift) | robust, IPF-specific, not module-specific |
| S2b (cell-state axis shift) | no true category (descriptive) |
| S3 (shared with COPD) | robust, module-specific, shared |
| S4 (no effect) | dropped |

S2b has no true category because the first principal component is often driven by a particular program, such as ribosomes or mitochondria. A shift along PC1 can correctly be module-specific for the modules that drive PC1. S2b is not judged. The report describes which modules are classified how, and why.

## Part A procedure (fixed)

Background: within each GSE136831 cell type, center each detected gene inside each true group (IPF, control, COPD), then add back that gene's overall mean.
Each replicate permutes disease labels once, at the donor level. Every cell type uses that same permuted labeling. Age and sex stay with the donor. The grid rule (at least 50 cells, at least 4 donors per group) is applied again on the permuted labels.
Effects are added only on detected genes, on the matrix that is the direct input to the clock. Genes filled by imputation are not used to carry the effect.
Directions: u_clock, u_eig, v_rand, v_pc1, as specified in instruction 6 section A-2.
Scenarios S1a, S1b, S2a, S2b, S3, S4 and the delta rules, including the S1b unreachable rule (required delta greater than 3 times the donor projection SD), are those in instruction 6 section A-3.
d is 0.5, 1.0, 1.5, 2.0. S4 has no d. Each replicate of S1a, S1b, and S3 picks one estimable module per testable cell type.
The full r5 gate, including the unestimable rule, is run every replicate.

## Part B procedure (fixed)

Corruption fractions f are 0.10, 0.25, 0.50, 1.00, with 20 replicates for the input check.
Per module, round(f times module size) genes are selected. The module assignments of the selected genes are permuted. Module sizes stay the same. Coefficients stay in their original rows.
A module is suspect if its in-sample r falls below 0.9 of the official in-sample r, or if the z of its mean pairwise correlation is below 3. The z reference is 1,000 size-matched random sets drawn from the union of module genes.
The module set fails if at least half of the 23 modules are suspect.
The same check is run on the official modules (f = 0) and on the spreadsheet Table 5B labels.
Downstream: f in 0.25, 0.50, 1.00, 10 replicates each of V1 (official coefficients on corrupted names) and V2 (refit on the corrupted gene set with the official pipeline and hyperparameters; l1_ratio 0 uses the ridge equivalent). Real GSE136831 labels. The spreadsheet labels are run once for V1 and once for V2.

## Part C procedure (fixed)

Groups, pseudobulk (mouse by cell type, at least 50 cells), and the grid (at least 4 mice per group, lowered to 3 only if fewer than 3 cell types would otherwise be testable) follow instruction 6 section C-3.
Preprocessing is the human tAge transplant, centered on the young median.
Scores are the 23 official mortality module clocks and the mortality and chronological composites.
Primary model: score ~ old + sex, with sex included only when both groups contain both sexes.
Three inferences, BH-FDR, and competitive nulls inside the hit set.
Sensitivities: continuous age on mice of at least 3 months; and, when candidate 2 is used, within-batch continuous age.
The positive-fraction p uses mouse-level age-label permutation, B = 2000, or the full enumeration if fewer permutations exist.
