Decisions (unchanged from the instruction):

1. All 23 official rodent module clocks are tested. No module is dropped. Cell-type disease results use the mortality clocks.
2. Reliability tiers come from instruction 3 `results/v3/rodent/rodent_cv.csv`. A module is tier 1 when its mortality dataset-held-out out-of-fold correlation is at least 0.30, and tier 2 otherwise. 0.30 is the original authors' inclusion threshold. Tiers annotate interpretation. The 253 tests are not reduced. The table also records whether the out-of-fold correlation exceeds the size-matched random-set mean. Saved as `module_tiers.csv` at this step.
3. A cell type enters the grid when each pseudobulk has at least 50 cells and the cell type has at least 4 IPF donors and at least 4 control donors.
4. The primary model is IPF-versus-control ordinary least squares on IPF and control donors only, with covariates age and sex, the same model as v0.2.0 Supplementary Table S9a.
5. COPD-versus-control and IPF-versus-COPD come from one three-group joint model (age and sex). The joint-model IPF-versus-control contrast is a sensitivity analysis.
6. Inference is classical, HC3, and Freedman-Lane permutation with B = 5000. Benjamini-Hochberg FDR is applied within each method across the 253 tests. An effect is robust when all three FDRs are below 0.10. An effect is IPF-specific when the primary IPF-control FDR is below 0.10 and the joint IPF-COPD FDR is below 0.10. The IPF-COPD FDR is computed only for pairs with at least 4 COPD donors.
7. Global effects use CR1 (t, degrees of freedom G-1), a wild cluster bootstrap (Rademacher, B = 9999), and a donor random-intercept mixed model.
8. Competitive nulls use random gene sets that are centered only (subtract the training mean, impute the training median), the same arithmetic as the official clock. For each effect with FDR below 0.10, two nulls (size-matched random genes, and coefficient permutation), 10,000 draws each, with FDR among those effects. Separately, all 253 tests are screened with 1,000 draws, with FDR across all 253. Both are reported under distinct names.
9. Masking decomposes the composite with the official membership of the deployed composite (1,292 genes inside modules, 9,195 outside). Permutation and donor bootstrap use B = 2000 each.
10. Sensitivity repeats the existing 11 analyses and adds the joint-model IPF-control contrast. Age overlap also uses the rule of at least 4 controls. Cell types below 4 are recorded as not testable (검정 불가). Per-effect coefficient ratios are saved. An effect is flagged when its ratio is below 0.5 under depth matching or cell-count matching.
11. Sub-state markers: INHBA stays only in the monocyte-derived set and is absent from the resident set. The saved stage-B pseudobulks already use that split (monocyte-derived: SPP1, FCN1, VCAN, CTHRC1, INHBA, MERTK, SPARC; resident: FABP4, MARCO, MRC1, PPARG).
12. Multiple-instance learning is not rerun. It will be removed from the manuscript.

Primary FDR threshold 0.10. Secondary threshold 0.05. A permutation p-value at the floor is written as p < 1/(B+1). Every number in the report comes from a saved file. Heavy loops use joblib. Wall time is recorded per step.

HLCA donor rule, taken from `scripts/hlca_pull_pseudobulk.py` and not changed: CELLxGENE census 2025-11-08, dataset 9f222629-9e39-47d0-b83f-e08d610c7479, tissue_general lung, disease normal, is_primary_data True, age at least 20. If more than 45 donors remain they are subsampled by age-stratified linspace. HLCA core is 107 donors. The stored pseudobulk is the result of that rule.
