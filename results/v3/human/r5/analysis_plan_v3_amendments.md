## A1. Unestimable scores

A test is marked unestimable, and removed from every Benjamini-Hochberg family, when the standard deviation of the scores of the donors in that test is below 1e-8.

Reason: if the score is constant, the coefficient and its standard error are floating-point noise and the t statistic has no meaning. This is a property of the arithmetic, independent of which biological result is desired.

## A2. Screen resolution

The screen of every test is rerun at B = 10,000 for each of the two nulls (size-matched random genes, and coefficient permutation), under the name screen_10000. Unestimable tests are excluded. screen_1000 is kept and labelled as resolution-limited.

Reason: with B = 1,000 the smallest permutation p is 1/1,001, about 1.0e-3. Discovering one test out of 253 at FDR 0.10 requires p at most 0.10/253, about 4.0e-4. Unless three or more tests sit on that floor, a discovery is impossible, so a count of zero cannot be interpreted. This is a property of the multiple-testing arithmetic in instruction 4.

## A3. Composition arm

For macrophages and monocytes, build a random-split pseudobulk and apply the checklist through the composition arm. The random split follows the v0.2.0 procedure: one split, seed fixed. Within each coarse cell type and donor, cells are assigned at random to two groups whose sizes match that donor's monocyte-derived and resident counts. Scores use the same scoring function and are stored as variant randsplit_001. GSE135893 is included where a sub-state is defined. Concordance uses B = 2,000 label permutations, the same count as v0.2.0.

Reason: the composition arm was in the frozen plan. It was not run because the instruction 4 score list omitted the random-split scores. That is an omission in the score list, not a change of the scientific rule.

## A4. All eligible HLCA donors

Remove the cap of 45 donors. Use every donor who meets the same rule: lung, disease normal, primary data, age at least 20. Report the existing 42-donor result beside the new one.

Reason: the cap is an arbitrary limit with no biological justification, and it reduces power. This amendment is fixed before seeing the full-cohort correlations.

## A5. Scrambled-membership null

Exploratory, for an author decision. It is not part of the primary funnel. Pool the input genes of the official mortality module clocks, reassign them at random to the 23 modules keeping each module's size, repeat B = 100, refit each clock on the full rodent training matrix with the official pipeline (median imputation, center-only scaling, the official alpha and l1_ratio; Ridge equivalent alpha_ridge = n * alpha when l1_ratio is 0), score the GSE136831 primary pseudobulks, and run the primary model with classical and HC3 errors. Freedman-Lane is omitted. If one repeat exceeds 10 minutes, reduce B and report why.

Reason: a scrambled assignment is the situation created by the mislabelled published spreadsheet. The question is how many IPF-grid hits that assignment produces. The procedure is fixed before seeing the hit-count distribution.
